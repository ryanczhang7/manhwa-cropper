## Context

The walking skeleton. Before any detector exists, the exe must take file
paths on the command line and put a file in the output folder, exercising
argument parsing, the exit-code contract and file writing end to end
(`architecture.md`, "manhwa-cropper" and decision 10). Nothing is decoded;
the bytes are copied. Argument parsing lives in `cropper-engine::args` so it
is unit-testable; `main.rs` only dispatches. The end-to-end test spawns the
built binary via `env!("CARGO_BIN_EXE_manhwa-cropper")`, which cargo provides
to integration tests of a crate with a binary target.

Gate that fails if this breaks: `unit` (the spawned-exe test and the args
tests run under `cargo test --workspace`).

## Acceptance criteria

- **AC-1** - Given a PNG file `a.png` and an existing empty directory `out`, when the exe runs with `--no-gui --out <out> <a.png>`, then `out/a.png` exists, its bytes equal the input's, and the exit code is 0.
- **AC-2** - Given `--out` names a directory that does not exist, when the exe runs with one existing input, then the directory is created, the copy is written and the exit code is 0.
- **AC-3** - Given an input path that does not exist, when the exe runs with `--no-gui --out <out> <missing>`, then nothing is written to `out` and the exit code is 1.
- **AC-4** - Given an unknown flag such as `--bogus`, when the exe runs, then nothing is written and the exit code is 2.
- **AC-5** - Given `argv` `["--no-gui", "--out", "D:/o", "a.png", "b.png"]`, when `cropper_engine::args::parse` runs, then it returns `Invocation { no_gui: true, out_dir: Some("D:/o"), inputs: ["a.png", "b.png"], summary_path: None }`; given `["--summary", "s.json", "a.png"]` it returns `summary_path: Some("s.json")`; given `["--out"]` with no value it returns an error.

## Model guidance

Model: default. Oracle partition: all **mechanical** - pin the exact
`Invocation` shape, exit codes and file bytes. Do not assert on stdout or
stderr; the exe is built with the Windows GUI subsystem (decision 10) and
those streams may be unattached.

## Out of scope

Decoding or cropping anything (MC-008), the run summary file (MC-011 and
MC-012), the fallback output folder when `--out` is absent (MC-012), the
settings file (MC-013), multiple inputs beyond parsing them (MC-011), the
window (EPIC-04).
