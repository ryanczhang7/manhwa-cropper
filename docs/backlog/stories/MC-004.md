## Context

The primitive behind the brief's second mechanism, "detect the art's edges so
that non-uniform regions outside the panel are also removed". This story
computes the profiles and finds strong lines; MC-005 uses them. From
`architecture.md` (`edges`): the row profile has one value per adjacent row
pair - the mean absolute luma difference between row `i` and row `i+1` over
the columns of a rect - and the column profile likewise. A strong line is a
run of consecutive indices at or above `edge_threshold`, merged into one
`Line { start, end }` (inclusive indices into the profile).

Gate that fails if this breaks: `unit`.

## Acceptance criteria

- **AC-1** - Given a `Luma` of height `H` whose rows `0..k` are constant luma `a` and rows `k..H` constant luma `b`, when `row_profile(&luma, full_rect)` runs, then it has length `H - 1`, value `|a - b|` at index `k - 1` and `0` everywhere else; and `col_profile` has length `W - 1` and is all `0`.
- **AC-2** - Given `row_profile` and `col_profile` are asked for a sub-rect, when computed, then only pixels inside the rect contribute (a bright band outside the rect changes nothing) and the lengths are `rect.h - 1` and `rect.w - 1`.
- **AC-3** - Given a profile with values `>= edge_threshold` at indices 10, 11, 12 and 40 only, when `strong_lines(&profile, &Tuning::default())` runs, then it returns `[Line { start: 10, end: 12 }, Line { start: 40, end: 40 }]`.
- **AC-4** - Given the two-band image from AC-1 with `|a - b| = edge_threshold` (24), when strong lines are computed, then exactly one line is found at `k - 1`; given `|a - b| = 23`, then none. *Control on the number:* 23 must produce no line.
- **AC-5** - Given a `Luma` of textured noise whose adjacent-row mean absolute difference is below `edge_threshold` everywhere (the generator's art texture; measured value recorded in the handoff), when strong lines are computed, then none are found - the art's own texture is not an edge.
- **AC-6** - Given a `Luma` with `H <= 1` (or a rect with `h <= 1`), when profiled, then the row profile is empty and `strong_lines` of an empty profile is empty.

## Model guidance

Model: default. Oracle partition:

- **Settled**: `edge_threshold = 24`. Read it out.
- **Mechanical**: `row_profile(&Luma, Rect) -> Vec<f32>`, `col_profile`, `strong_lines(&[f32], &Tuning) -> Vec<Line>`, `Line { start: usize, end: usize }`. Pin exactly.
- **Oracle-free**: AC-5's texture. The generator's texture must be measured, not assumed, and the handoff records the measured maximum adjacent-row difference so GREEN can confirm it is below 24 with room (target: below 16).

## Out of scope

Deciding which side of a strong line is chrome (MC-005), diagonal or curved
edges, sub-pixel positions, gradient operators beyond the adjacent difference
(no Sobel, no blur), colour edges (luma only).
