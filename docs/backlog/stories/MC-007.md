## Context

The brief's feature 3: when no confident crop is found, say so rather than
guess. This story adds `decide(&Luma, &Tuning) -> CropDecision` on top of
`detect` (MC-006) with the discrete reasons from `architecture.md` (Data
model, decision 3): `Uniform`, `NoBorderFound`, `LowContent`, `Ambiguous`.
The engine will copy a flagged file unchanged; the core only decides.

Gate that fails if this breaks: `unit`.

## Acceptance criteria

- **AC-1** - Given a uniform image, when `decide` runs, then it returns `Flag(Uniform)`.
- **AC-2** - Given an image where the trim removed nothing and no strip was peeled (the whole screenshot is art), when `decide` runs, then it returns `Flag(NoBorderFound)` even though `detect` returned a rect equal to the full image.
- **AC-3** - Given the detected rect's area is below `min_content_fraction` (0.20) of the image area, or either side is below `min_content_side` (64 px), when `decide` runs, then it returns `Flag(LowContent)`. *Controls on the numbers:* a rect at 19% of the area is flagged and at 21% is cropped; a 63 px side is flagged and a 64 px side is cropped, each with the other dimension well inside the limits.
- **AC-4** - Given `detect` reports `ambiguous == true`, when `decide` runs, then it returns `Flag(Ambiguous)` regardless of the rect.
- **AC-5** - Given none of the above, when `decide` runs, then it returns `Crop(rect)` with the rect `detect` produced.
- **AC-6** - Given the reasons are checked in the order AC-1, AC-2, AC-4, AC-3, when an image is both ambiguous and low-content, then `Ambiguous` wins (the order is the contract; pin it).

## Model guidance

Model: default. Oracle partition:

- **Settled**: `min_content_fraction = 0.20`, `min_content_side = 64`.
- **Mechanical**: `CropDecision { Crop(Rect), Flag(FlagReason) }`, `FlagReason { Uniform, NoBorderFound, LowContent, Ambiguous }`, both deriving `Debug, Clone, PartialEq, Eq` and `serde::Serialize` (the summary will serialise them). Pin, including the precedence in AC-6.
- **Oracle-free**: none.

## Out of scope

Copying the file (engine, MC-009/MC-011), the words shown to the user for each
reason (`docs/wiki/design/voice.md`, MC-015), a numeric confidence score
(decision 3), any new detection heuristic.
