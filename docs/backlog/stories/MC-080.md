of `n05`, `2025-10-26 12_13_16.png` (`toongod`, dark, 2560x1440):

- the user's mark: `973,167 600x1233`, columns **973..1573**;

a zoomed picture, the user ruled **"Box starts at 1007"**, and MC-073 became
a re-mark with no code change. A rule that kept that column would have moved
(3605) and `10_20` outward again (MC-070's candidate B).
