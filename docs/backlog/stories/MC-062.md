## Context

**The request (2026-09-30).** After MC-059's negative, the user chose a fresh
set: *"we can get a fresh set. instead of me sourcing them, can you search in
the folders I have specified before for screenshots not already cropped, that
havent been used before."* Their answers to the follow-up questions, the same
day:

- **Folders:** the eight the corpus came from and nothing else ("everything is
  already in. dont include anything else"): `Downloads\mahwa panels`, and in
  `OneDrive\Pictures\Screenshots 1` the series folders Demonic Evolution,
  Eleceed, Hero Killer, Jungle Juice, Pick Me Up Infinite Gacha, Unholy Blood
  and Suicidal Battle God.
- **"Not already cropped"** means whole-screen captures only, not the user's
  own trimmed or stitched panel images.
- **Picked** at random, spread over the series, by an agent that does not look
  at them.
- **Space:** raise the corpus ceiling, `MAX_BYTES`, from 60 MiB to 100 MiB.
  The corpus is 61,587,028 bytes (58.7 MiB) today.

**Why a representative set, and not a hunt for site headers.** The user
pointed out that a site's own header shows only when the page is scrolled to
the top of a chapter. So a held-out set chosen to contain headers would test
something rarer than real use. A random draw of whole-screen captures shows
headers about as often as real use does.

### The draw, done 2026-09-30 before anyone looked at a drawn image

Everything here was read from **names, sizes and file headers only**. No
drawn file has been decoded, displayed or measured by an agent, and it must
not be until the user has marked it (AC-2). The scripts live outside the

   panels 541, Eleceed 355, Hero Killer 472, Unholy Blood 111. None is
   1920x1080.
3. **Order.** Within each folder, by `sha256("MC-062|2026-09-30|<folder>|<file
   name>")`, ascending.
4. **No near-twins.** A file is skipped when it was captured within 30
   minutes of any corpus screenshot or any file already drawn (times read from
   `YYYY-MM-DD HH_MM` names), or, for `Screenshot (N)` names, within 20 of
   any such number. Two frames of one reading session are one test, not two.
5. **Quotas, 25 in all.** An equal share of about 6 per folder, capped by what
   the no-twin rule leaves (Hero Killer spans 4 capture days, Unholy Blood 3),
   and the rest split evenly: **mahwa panels 9, Eleceed 9, Hero Killer 4,
   Unholy Blood 3.** No folder ran short.

**Two corrections made on the way, both before any image was seen.** The
first run's whole-screen test was a ratio (width at least 1600, width/height
1.5 to 1.9). It admitted two wide stitched images (3740x2224, and 4736x2570 at
11.9 MB), so it became the exact sizes above. The second run's twin rule only
compared files within a folder, by day. 12 of its 25 turned out to be taken on
the same day as a corpus screenshot, one of them 3 minutes after it, so the
rule became the 30-minute rule above, against the corpus too. The seed never

## Acceptance criteria (draft, to settle with the user before RED)

- **AC-1: the files.** The 25 are copied into `fixtures/corpus/` byte for
  byte (each copy's SHA-256 matches the table). Where a name collides with an
  existing corpus file, the copy is renamed and the old and new names are
  recorded in `corpus.md`.
- **AC-2: the marks are the user's.** The user marks every one on a page that
  draws nothing but the screenshot and their own lines: the art box, or "flag"
  with its reason, and the reading site from the address bar. Answers are read
  back with `ArtifactData`, never pasted. No agent views a drawn image before
  that. The manifest gains 25 entries, with `split: "held-out"` and a
  `site:` tag each.
- **AC-3: the ceiling.** `MAX_BYTES` is 100 MiB, pinned, and watched to fail
  at 60 MiB with the new files in place.
- **AC-4: fresh is told apart from spent.** A run over held-out can no longer
  mix the 25 fresh entries with the 26 spent ones (Open question 1).
- **AC-5: the floors.** At least 20 fresh marked entries (MIN_ENTRIES'
  reasoning: one miss is 5 %). If the user flags more than 5 of the 25, the
  draw continues with the same seed, order and rules until 20 marked are in.
- **AC-6: the record.** `corpus.md` gains the draw (this section's steps, the
  table, both corrections) and the new counts.

The one scored run on the fresh set is **not** this story. It follows as an
MC-051-shaped spike.

   *Recommended:* move them into the practice set. Any later rule may then be
   tuned on them, and "held-out" means only screenshots nothing has been run
   on. The alternative is a new label, "spent", which keeps them out of both.

   rulings, holding the 25 full-size screenshots. You drag or type the four
   edges of the art box with a magnifier, or press "flag" and say why, and
   pick the site. About 25 to 40 minutes in all.
